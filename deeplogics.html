Endpoints

Core API

POST /v2/chat/completions Streaming Auth Required

Generate a model response to a conversation. Supports streaming via SSE.

curl -X POST https://api.deeplogics.ai/v2/chat/completions \
  -H "Authorization: Bearer $DL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deeplogics-2",
    "messages": [
      {"role": "user", "content": "Hello!"}
    ],
    "stream": true
  }'
POST /v2/embeddings Vector

Create embedding vectors for text inputs — useful for semantic search and RAG.

curl https://api.deeplogics.ai/v2/embeddings \
  -H "Authorization: Bearer $DL_API_KEY" \
  -d '{"input": "Your text here", "model": "dl-embed-2"}'
